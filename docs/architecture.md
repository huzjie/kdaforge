# kdaforge 架构

kdaforge 是 Kimi K3.1 Pro 关键架构思想的零依赖参考实现：**混合线性注意力（KDA）+ 超大稀疏 MoE**。四大可独立调优的组件：

```
┌──────────────────────────────────────────────────────────┐
│                      请求 / 序列                          │
└───────────────┬──────────────────────────────────────────┘
                │
   ┌────────────▼────────────┐
   │  attention / hybrid     │  69 层 KDA（Gated DeltaNet 循环态）
   │  混合注意力栈            │  + 24 层 Gated MLA（全注意力）
   └────────────┬────────────┘
                │
   ┌────────────▼────────────┐
   │  moe / latent_moe       │  896 专家 top-16 + aux 负载均衡
   │  Stable LatentMoE       │  + 逐专家偏置校正
   └────────────┬────────────┘
                │
   ┌────────────▼────────────┐
   │  serving / speculate    │  投机解码 + 批调度 + KV 预取
   │  Highspeed serving      │  （2-3x）
   └─────────────────────────┘

   mopd（后训练）：沙箱自动奖励 + 自生成多教师 + 在线策略蒸馏
```

关键设计原则：**声明规模与实例化解耦**。config 里的 `declared`（2.8T / 104B 激活 / 896 专家 / 1M 上下文）只用于口径表达，参考实现实例化的是 tiny 结构（64 维 / 16 专家 / 6 层），让一次前向在毫秒级跑完。
