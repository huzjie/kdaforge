# MOPD：不靠闭源教师的后训练

Kimi K3.1 是「基座不动、后训练加码」。它的后训练用 MOPD（多教师在线策略蒸馏），核心约束是：**不依赖外部闭源教师，也不靠人类标注**。

## 三个角色

- **沙箱**：确定性环境，自动打分（action 对/错），是唯一的奖励来源
- **教师**：模型自己的更好 rollout（更高 skill + 不同 seed），ensemble 成蒸馏目标
- **学生**：softmax 策略，在线采样 → 沙箱奖励 → 拉向教师分布

## 为什么「多教师」

多个教师（不同 seed / 不同 skill）的分布取平均，比单一教师更平滑、更抗过拟合。KL 蒸馏项把学生拉向教师，策略梯度项把学生拉向高奖励动作——两者方向一致，因为教师本身就更擅长高分动作。

## 复现要点

- 训练信号保持**单调趋 1**：`skill += lr·(1-skill)`，不要用「对 +1 错 -1」的随机游走（低起点会被压到 0）。
- 沙箱奖励必须**可复现**（md5 种子），否则训练曲线无法复现。
