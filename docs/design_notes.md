# 设计笔记

## 为什么是「声明规模与实例化解耦」

纯 Python 实例化真实的 896 专家 × 2048 维权重会直接卡死。所以 config 里分两层：
`declared`（2.8T / 896 专家 / 1M 上下文）只做口径表达，实际实例化的是 tiny 结构。
这是参考实现的通行手法，也避免了「demo 跑不动」的坑。

## 为什么用 md5 做确定性随机

所有 mock 信号、oracle、教师、基准共享同一 md5(key) 种子，任何输出可复现。
md5 前 8 字节做 `random.Random` 种子，比逐坐标 md5 快一个数量级（老坑）。

## 为什么训练信号要单调趋 1

`skill += lr(1-skill)` 是几何爬升、恒正。若用「对 +1 错 -1」，低起点 skill 的期望漂移
为负，会被压到 0——这是本系列项目反复踩过的坑。
